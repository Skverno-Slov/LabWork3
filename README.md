# LabWork3
## Описание
Репозиторий 3-ей лабораторной. Создание нового репозиртория.
## Установка 
Склонируйте репозиторий:
bash
git clone https://github.com/Skverno-Slov/LabWork3.git
dotnet build
## Использование 
Bash dotnet run
## Системеные требования:
* ОС: 64-разрядная Windows 10 или Windows 11.
* Процессор: Intel Core i5-2500K (3.3 ГГц) или AMD A10-5800K (3.8 ГГц).
* Видеокарта: NVIDIA GeForce GTX 660 или AMD Radeon HD 7870 (2 ГБ видеопамяти).
* Оперативная память: 6 ГБ.
* DirectX: версия 11.
* Место на диске: 50 ГБ.
## Контрибъютинг
* Стиль – code style C#
* Создавать новую ветку отличную от main для нового функционала
